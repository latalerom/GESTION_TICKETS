TicketFlow

Politica de privacidad

Recolectamos solo los datos necesarios para crear cuentas, autenticar usuarios, gestionar tickets y mantener trazabilidad de soporte.

Datos tratados

Nombre, correo, telefono, cargo o area, informacion adicional opcional, foto de perfil opcional, datos de tickets, historial de cambios y direccion IP al crear invitaciones.

Finalidad

Usamos estos datos para prestar soporte, administrar accesos, enviar notificaciones operativas, auditar cambios y proteger la seguridad del sistema.

Conservacion

La informacion se conserva mientras exista una relacion de soporte o una obligacion operativa o legal. Los datos opcionales pueden eliminarse desde el perfil cuando no sean necesarios.

Derechos

Los usuarios pueden solicitar acceso, correccion o eliminacion de datos cuando aplique, contactando al administrador del sistema.

Seguridad

Las contrasenas se almacenan con hash. El acceso depende de sesion autenticada y permisos por rol.
