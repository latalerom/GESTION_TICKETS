# Atribucion de imagenes

Este proyecto no carga imagenes de terceros desde internet. Antes de publicar o distribuir la aplicacion, confirma que estos archivos sean propios, generados para el proyecto o tengan licencia de uso:

- `favicon_logo.png`
- `logo_princiopal.png`
- `portada_mobile.png`

Si se reemplaza alguna imagen, registra aqui la fuente, licencia, autor y fecha de descarga o generacion.
